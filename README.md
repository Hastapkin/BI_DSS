# Business Intelligence & Decision Support: Superstore

Three labs from a Business Intelligence and Decision Support Systems course, all built on the Sample Superstore sales dataset. Together they cover the path from a flat file to a report: analysis in Excel and Power BI, an ETL package, and an OLAP cube.

| Lab | Tools | What is in it |
|---|---|---|
| `lab1` | Excel, Power BI | Pivot-table analysis (`Lab1_Analysis.xlsx`) and a Power BI report (`lab1_22521609.pbix`) on `SampleSuperstore.csv` |
| `lab2` | SQL Server Integration Services (SSIS) | An SSIS project with the ETL package `Package.dtsx` |
| `lab3` | SQL Server Analysis Services (SSAS) | A multidimensional cube, `Superstore DB`, on a star schema: Customer, Location, Product and Shipping dimensions around one fact table |

## Opening the projects

- `lab1`: Power BI Desktop and Excel.
- `lab2`, `lab3`: Visual Studio with the SQL Server Integration Services and Analysis Services extensions, plus a SQL Server instance for the data source.
